# Changelog

## [1.0.0] - 2026-07-22

### Added

- Encrypt/decrypt text for individual contacts using HPKE + AES-256-GCM.
- Multi-profile support with key rotation.
- Contact management with fingerprint verification.
- Biometric app unlock.
- Encrypted local storage.
- Replay protection with send/receive counters.
- Custom keyboard IME with 8 language layouts.
- Accessibility service for screen-scanner decryption.
- QR code scanning and generation for key exchange.
- No network access, no accounts, no analytics.
